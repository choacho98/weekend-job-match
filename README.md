# 周末搭子 Weekend Buddy

面向大学生与校园周边需求方的周末兼职撮合平台原型。平台把大学生的碎片时间转化为可匹配的服务供给，覆盖门店协助、家教陪练、宠物照护、活动协作、内容拍摄和便民服务。

在线体验：<https://weekend-job-match.chaoyaz98.chatgpt.site>

## 产品逻辑

1. **时间先过筛**：学生登记周末可用时段，需求方明确开始、结束时间。
2. **距离内召回**：优先匹配校园周边 3 公里内的需求，降低通勤成本。
3. **技能与偏好排序**：结合技能、兴趣、期望收入和工作类型计算匹配度。
4. **信用动态加权**：实名、准时、履约记录影响后续推荐顺序。
5. **履约形成闭环**：报名、确认、到岗、工时、验收和结算都有记录。

## 已实现功能

- 学生端与商家端身份切换
- 周末时段与兼职类型筛选
- 关键词搜索和智能推荐岗位
- 岗位详情与一键报名演示
- 商家快速发布需求表单
- AI 匹配分及匹配原因展示
- 实名审核、电子约定、信用记录与争议协助说明
- 桌面端和移动端响应式布局

> 当前版本为产品原型，岗位、商家和数据均为演示内容；报名与发布不会产生真实交易。

## 本地运行

这是一个无构建步骤的静态网站。进入 `dist` 目录后，用任意静态文件服务器打开即可，例如：

```bash
npx serve .
```

也可以直接打开 `dist/index.html` 浏览主要页面；建议使用静态服务器以获得更稳定的资源加载体验。
